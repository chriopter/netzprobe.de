# Netzprobe

Statische Stromnetz-Simulation für Deutschland. Szenario einstellen, Lastdeckung, Speicher, Abregelung und CO₂ sehen.

## Start

```bash
npm install
npm run dev
```

## Prüfung

```bash
npm test
npm run build
```

## Veröffentlichung

```bash
npm run build
```

Dann `dist/` statisch ausliefern.
